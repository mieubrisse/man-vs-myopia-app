# Project Information for Claude

## Build System
This project uses Vite as the build tool and development server.

## Development
- The app auto-reloads during development when files are changed
- No need to manually run `npm run build` for testing changes during development
- Vite provides hot module replacement for fast development iteration

## TypeScript
- Project uses TypeScript with strict type checking
- Build errors will prevent deployment on platforms like Vercel
